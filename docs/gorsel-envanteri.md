## Yapılacaklar

1. **10 lekeli fotoğraf** panelden yeniden yüklenmeli (orijinalleri yalnızca sizin
   cihazınızda). Yeni panel hiçbir efekt uygulamaz, yalnızca 1200×1600'e küçültür.
   Öncelik sırası: ana sayfadaki Haute Couture vitrini → Ev Renovasyon galerisi →
   Mor Kimono → Sarı Kaftan galeri 4.
2. **Ev Renovasyon'un fotoğrafları** düşük çözünürlüklü (ör. 500×374). Orijinalleri
   daha büyükse yeniden yükleme aynı zamanda netlik kazandırır.
3. **Yıldız işareti**: 10 dosyada duruyor. Kalması, kırpılması ya da kaynaktan
   işaretsiz yeniden üretilmesi kullanıcının kararına bırakıldı.

## Yeniden ölçmek için

python scripts/kose-bulaniklik-olc.py                       # public/images/products tümü
python scripts/kose-bulaniklik-olc.py yol/ile/dosya.jpg     # tek dosya
